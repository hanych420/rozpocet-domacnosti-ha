# Changelog

## 0.6.2
- Výplata má skutečné datum přijetí a samostatné rozpočtové období.
- Výplata přijatá 12.–14. den se automaticky přiřadí k období začínajícímu 15. stejného měsíce, takže při přepnutí období nezmizí.
- Přehled roku používá přesnější názvy souhrnů domácnosti a ukazuje rozpad Hanych / Eva.
- Graf „Společné výdaje po měsících“ ukáže při najetí myší nebo dotyku přesnou částku.
