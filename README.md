# Rozpočet domácnosti – Home Assistant

Soukromá aplikace pro domácí rozpočet Hanych & Eva.

- SQLite databáze běží lokálně na Raspberry Pi
- osobní finance se počítají v období 15.–14.
- společné finance se zobrazují po kalendářních měsících
- průběžný stav společného konta
- denní zálohy do `/share/rozpocet_domacnosti_backups`

Finanční data ani zálohy nejsou součástí tohoto veřejného repozitáře.
